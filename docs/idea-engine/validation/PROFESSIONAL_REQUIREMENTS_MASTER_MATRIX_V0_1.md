# 4b4c — PROFESSIONAL REQUIREMENTS MASTER MATRIX — V0.1

Date : 2026-09-13

Statut : **WORKING CANDIDATE — NON CANONIQUE / À RED-TEAMER**

Périmètre actuel : Blueprint `SITE_VITRINE`.

But : recenser les besoins professionnels à résoudre entre une idée brute et un Projet figé `READY_FOR_DEVELOPMENT`, en séparant clairement :

- ce qui appartient à **IDEA** ;
- ce qui appartient à **PROJECT / PRE-DEVELOPMENT** ;
- ce qui appartient seulement à **DEVELOPMENT / PRODUCTION**.

Ce document ne doit jamais devenir un formulaire visible complet. Il sert de registre de couverture et de dépendances.

---

# 0. Principes de fonctionnement

Pour chaque information/question :

1. chercher d'abord dans RAW / mémoire / sources ;
2. extraire depuis site/documents/données si possible ;
3. rechercher publiquement si légitime ;
4. calculer/dériver ;
5. utiliser une hypothèse IA réversible si suffisante ;
6. demander à l'humain uniquement si l'humain seul sait/arbitre ;
7. accepter l'inconnu si non bloquant.

Une section possède un **exit criterion**, mais cela ne crée pas nécessairement un écran ou une étape visible.

Un travail aval peut être préparé en parallèle ; il ne peut pas être **figé** si une dépendance amont structurante reste instable.

- Budget réellement plafonné ?
