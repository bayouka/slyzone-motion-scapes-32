# 2b2c / 4b4c — Pre-collaborator readiness audit

This document records the checks required before real collaborators are invited.

## Product contract
- Home is a personal situation summary: attention, time, awareness, continuity.
- Project visibility and project responsibility are distinct.
- Messages are audience-first; notifications are reserved for mentions and obligations.
- External/guest access is shared-only and project-scoped.
- Mobile is a deliberate single-column flow, not a compressed desktop.

## Must pass before invitation
1. Selected-project members cannot read data from unselected projects.
2. Guests cannot write internal project content or read internal files.
3. Invitations bind to the invited email and project mappings.
4. Direct/group/project messages preserve their audience; unread and mentions work cross-user.
5. File version numbers are assigned safely when several users work at once; failed registrations clean uploaded objects.
6. Home upcoming meetings are personal/relevant, not every meeting visible in the workspace.
7. `Mon travail` and Home attention counts describe the same intervention model.
8. Navigation labels describe what the product actually does.
9. Missing live configuration fails visibly rather than loading a nonexistent fallback bundle.
10. CI and Cloudflare production smoke tests remain green.

Built-in video/screen-sharing is not claimed by the current pilot; meetings can store an external meeting link/room and structured before/live/after notes.
